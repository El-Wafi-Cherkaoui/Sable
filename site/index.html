Sharing

Read it before it runs.

Commit a sable.json and your whole team gets the same setup. When you open someone else's, Sable shows you every command before anything runs.

If the file changes later, you see exactly what changed first. Secrets stay on your machine, never in the file.

One key, one meaning, on every screen.

No cheat sheet needed. The footer shows the keys that work right now, and ? shows the rest.

  • aadda workspace or item
  • eediteverything in one form
  • ddeletealways asks first
  • mmovereorder the list
  • sstart / stopor run a command
  • rrestartor run again
  • Sstart allin your order
  • Enteropenlogs or workspace
  • Escbackone level, or q
  • ?helpon every screen
  • ,settingssound, tips, saved logs
  • Ctrl+Cquitand stop everything

Scope

What Sable isn't.

Sable stays small on purpose. It runs your project's services and scripts on your machine, and that's it.

  • ✕a task runnerIt runs what you already have. It doesn't define tasks or pipelines.
  • ✕tmuxNo panes or splits. One dashboard per project.
  • ✕an IDEKeep your editor. Sable sits next to it.
  • ✕a Docker managerIt can run docker compose up like any other command.
  • ✕an AI toolNo models, no prompts, no account.
